# Security Policy

This marketplace ships configuration plus example skills; the repository itself executes no privileged code. Reference skills that run commands (the examples declare `allowed-tools: Bash`) do so locally under Claude Code's permission model. If you find a security concern — a malicious payload path, a skill that could exfiltrate data, or a supply-chain risk — please report it **privately**.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting: **Security tab → Report a vulnerability** on this repository. Please do **not** open a public issue for security reports.

> **Forkers:** this policy travels with your fork — reports go to *your* repository's Security tab, i.e. to you. Enable private vulnerability reporting in your fork's settings (Settings → Code security) so the button works.

You can expect an acknowledgement within a few days and updates as a fix is prepared.
